Astro Orbit is a free portfolio and blog theme for Astro. It's MIT-licensed, so you can use it for your own website, change it and publish it.

## What you need

- Node 22.23.4 or later
- pnpm 10
- Git

## Install it

```bash
git clone https://github.com/hansmartensdev/Astro-Orbit.git my-site
cd my-site
pnpm install
pnpm dev
```

The site runs at `http://localhost:4321`. When you save a change, the page in your browser updates.

## The commands

| Command | What it does |
|---------|--------------|
| `pnpm dev` | Runs the site on your computer at `http://localhost:4321` |
| `pnpm build` | Builds the static site, then the search index |
| `pnpm preview` | Serves the build. Search only works here, not in `pnpm dev` |
| `pnpm check` | Astro and TypeScript diagnostics |
| `pnpm lint` | ESLint |
| `pnpm test` | Unit tests: the language files, dates, post folders and the newsletter link |

## Put it online

Astro Orbit builds for [Vercel](https://vercel.com). Push your copy to GitHub, import the repository in Vercel, and it builds. Every page is a static file, except the contact form's and the newsletter's endpoints, which run as Vercel functions.

## The contact form

The contact form sends messages through [Resend](https://resend.com). Set these in the Vercel project's environment variables:

| Variable | What it does |
|----------|--------------|
| `RESEND_API_KEY` | Your Resend API key. Without it, the form doesn't send in production. |
| `CONTACT_TO` | Where messages go. |
| `CONTACT_FROM` | The sender, on a domain you've verified in Resend. |

The newsletter under every post uses the same key, with `CONTACT_FROM` as the sender of its confirmation email. `NEWSLETTER_SEGMENT_ID` is the Resend segment new subscribers go into.
