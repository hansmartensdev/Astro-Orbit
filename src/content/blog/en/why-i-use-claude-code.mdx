I'm Hans Martens, an Astro developer in Veghel, the Netherlands. I build my websites and my free Astro themes with [Claude Code](https://www.anthropic.com/claude-code), Anthropic's coding tool. I use it with Opus 5.5, mostly on my desktop and sometimes on my phone.

## Claude Code works in my GitHub repositories

My projects are on GitHub, and Claude Code works in those repositories. It makes its changes on a branch, and I review them and merge them myself.

## I bring the ideas, Claude Code advises on the code

While I build, I talk with Claude Code the whole time. We brainstorm first, then we build. The ideas are mine. Claude tells me what's possible in the code and advises me on how to do it. We work as a team.

## Example: the LetterGlitch effect in Astro Rocket

In another developer's theme, [Gothsec's Astro portfolio](https://github.com/Gothsec/Astro-portfolio), I found a canvas effect of flickering letters. I showed the code to Claude Code, and from it Claude built a new component for Astro Rocket: a field of letters in the theme's brand colours behind a call-to-action card, with a glass card on top to keep the text readable. We wrote a post about it on the Astro Rocket blog: [Add a LetterGlitch Effect to Astro 7](https://astrorocket.dev/blog/letter-glitch-astro-7).

In August 2026 another user of Astro Rocket reported a performance problem with the component ([issue #646](https://github.com/hansmartensdev/Astro-Rocket/issues/646)). Claude Code solved it: the animation no longer runs while the effect is off screen, and the colours are no longer worked out again on every frame. The component works fine now.

## A fork grows into a new theme

It starts with a fork. I fork a theme on GitHub, Velocity for example, and with Claude Code I build what I need for myself and the fork doesn't have. After a lot of work, the build has grown into a new theme of its own, and other developers use it for their websites.

## Astro Rocket started as a fork of Velocity

Astro Rocket began as a fork of the first public release of [Velocity](https://github.com/southwellmedia/velocity), when it was still a boilerplate. That release already had good components, and the credit for those goes to the team at Southwell Media. I never pulled in their later updates. I developed the code further with Claude Code and added components of my own, built my previous website with it in March 2026, and made [Astro Rocket](https://github.com/hansmartensdev/Astro-Rocket) from that website. It's free and public on GitHub under the MIT licence, and it's listed in the themes directory on the official Astro website.

## People who use Astro Rocket help me make it better

People who use Astro Rocket report issues on GitHub, and I solve them with Claude Code. Two people from the Astro community reported issues and came with ideas to solve them, and GitHub now lists them as contributors. That's one of the things I like most about this work: I build something for myself and for others, and the others help me make the code better by reporting what goes wrong.

## Building a client portal and a members area taught me a lot

With Claude Code I built two solutions for Astro Rocket: a client portal, where each client signs in and sees their own projects and invoices, and a members area, with content that only signed-in members can read. I don't use them myself. I built them for the love of the craft. While building them I learned a lot from Claude, and making both work on my own website made me more experienced. Claude Code is a good teacher too.
